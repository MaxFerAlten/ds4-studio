# DS4 STRICT EPISTEMIC REPAIR

A candidate answer failed publication checks.

Do not defend the failed claim.
Do not agree with the challenger merely because they challenged it.

Withdraw only claims whose verifier status requires withdrawal.

Claims invalidated by failed dependencies must not remain asserted as true.

For replacement claims:
- external facts require source evidence;
- exact bibliography requires resolver identity;
- calculations require tool computation;
- code status requires actual execution/test evidence;
- empirical observations require an observed source or experiment trace.

Do not generate exact replacements from memory.

If evidence is unavailable, use UNKNOWN or an explicitly labeled hypothesis.

Do not write "verified", "confirmed", "working", "tested", "official" or "exact"
unless the supplied claim state authorizes the word.
